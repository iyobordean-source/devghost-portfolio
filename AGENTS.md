# Agent instructions

- Read all project documentation before making implementation changes.
- Treat `PRODUCT.md`, `DESIGN.md`, `ARCHITECTURE.md`, and `TODO.md` as project source-of-truth documents.
- Do not randomly reorganize the project.
- Do not create unnecessary folders or components.
- Do not install unnecessary dependencies.
- Do not change the design direction without updating `DESIGN.md`.
- Do not change product scope without updating `PRODUCT.md`.
- Work on one focused task at a time.
- Do not implement features that are not part of the current task.
- Keep the codebase simple and maintainable.
- Verify changes after implementation.
